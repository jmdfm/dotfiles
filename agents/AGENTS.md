# Global agent instructions

Linked into Claude Code (`~/.claude/CLAUDE.md`) and Codex (`~/.codex/AGENTS.md`)
from ~/.dotfiles/agents/AGENTS.md. Keep it portable: machine- or
employer-specific instructions go in local, untracked files.

- Be brief. Prefer information density to prose.
- Shell (~/.zshrc, ~/.zshenv), git (~/.config/git/config), ssh (~/.ssh/config),
  mise and most ~/.config entries are generated by home-manager from
  ~/.dotfiles (a public repo; see its AGENTS.md). Edit the repo, never the
  generated files. Personal bits go in the machine-local files listed there
  (~/.config/git/local, ~/.ssh/config.local, ~/.zshrc.local).
- On Omarchy machines, Omarchy owns the desktop, nvim (LazyVim), starship and
  core CLI tools; customize those the Omarchy way, not through ~/.dotfiles.
- Language runtimes come from mise where it is installed (`mise use`), not
  from system packages.
- Public repos: never write real emails, hostnames, IPs, ssh users, home paths
  or employer names into code, docs, tests or commit messages. Use
  placeholders.
- Commits are SSH-signed; don't pass --no-gpg-sign or change signing config.
